# KOL Tracker — 红人合作全链路管理工具

> **痛点**：运营同时管几十上百个红人合作，私信列表乱、Excel 表格散、跟进全靠记忆——漏单、忘付款、不知道谁在哪个阶段是常态。
>
> **KOL Tracker** 把私信、表格、财务、效果数据全合并到一个工具里，从第一次发 DM 到付款完成，每一步都有据可查。

**线上地址**：[https://kol-tracker-woad.vercel.app](https://kol-tracker-woad.vercel.app)

---

## 这个工具是做什么的

你在跟 10 个、50 个、100 个 Twitter/X 红人谈合作。每个人都在不同阶段——有的刚发完 DM，有的在谈价格，有的稿子还没审完，有的发票还没付。

KOL Tracker 帮你把这些全部理清楚：

- **谁在哪个阶段？** — 一眼看到每个红人的当前状态
- **谁需要跟进？** — 超期未联系的自动标红提醒
- **钱的情况怎么样？** — 合同金额、开票状态、待付款汇总
- **效果怎么样？** — 每个红人专属追踪链接，实时看点击 / 转化数据

## 核心工作流

```
发现红人
   │
   ▼
添加到红人库（填入 Twitter 账号，自动拉取头像 / 简介 / 粉丝数）
   │
   ▼
推进合作阶段：待接触 → 已发DM → 谈判中 → 已签约
   │                                         │
   │                               生成专属追踪链接
   │                               发给受众，追踪点击 / 转化
   ▼
合作中：提交 Draft1 → Draft2 → 待发布 → 已发送
   │
   ▼
财务收尾：已发Invoice → 已付款 → 完成
```

## 功能介绍

### 首页仪表盘

打开产品第一眼看到的总览页，所有关键数字一屏呈现：

- **红人总数** — 库里当前管理的红人总量
- **本周新增** — 本周加入的新红人数，直观看增速
- **待跟进** — 设置了下次跟进日期但已过期且未完成的红人数，数字 > 0 时红色高亮提醒
- **本月完成** — 本月走完全流程（到达"完成"阶段）的红人数
- **待付款金额** — 已开票但尚未付款的合同金额汇总
- **各阶段分布** — 每个阶段有多少人，一眼看清全局进展

---

### 红人库

所有红人的主列表页，支持两种视图：

**表格视图**
- 显示头像、用户名、粉丝数、分类、当前阶段、负责人、下次跟进日期
- 点击任意一行进入该红人详情页
- 逾期跟进的行自动显示红色角标提醒
- 行尾菜单直接切换阶段，UI 即时响应（乐观更新）

**看板视图**
- 按合作阶段分列展示（接触中 / 商务期 / 制作中 / 发布收尾 / 财务）
- 拖拽卡片直接改阶段，UI 即时响应（乐观更新），后台同步数据库

**搜索与筛选**（即时响应，无需等待服务端）
- 关键词搜索：按用户名、备注模糊匹配
- 阶段筛选：从下拉选择具体阶段
- 分类筛选：按美妆 / 科技 / 游戏等分类过滤
- 逾期跟进 toggle：一键只看需要立刻跟进的人
- 活跃筛选条件以 Badge 显示，支持单独或一键清空
- 筛选状态保存在 URL，刷新不丢失

**批量操作**
- 勾选多行后顶部出现蓝色操作栏
- 批量改阶段：一次性把多个红人移到同一阶段
- 批量分配负责人：一次性指定多人的跟进负责人
- 一键取消全选

**数据导入导出**
- **导入 CSV**：按模板批量导入红人，支持字段自动映射
- **导出 CSV**：导出当前筛选结果（不是全量），含 BOM 标记，Excel 直接打开中文不乱码

---

### 红人详情页（6 个 Tab）

点击红人行进入，所有信息集中在此管理：

**① 基础 & 合作**
- 编辑 Twitter 账号、粉丝数、分类、备注
- 设置负责人、下次跟进日期
- 管理合作信息：合作类型、报价、合同金额、合同链接
- 追踪稿件进度：Draft1 / Draft2 链接 + 完成状态、预计发布日期、发布后链接

**② 财务**
- 填写发票编号、发票金额
- 更新付款状态（未开票 / 已开票 / 已付款）
- 记录付款截止日期和实际付款日期
- 付款阶段与合作阶段联动（进入"已发Invoice"自动同步付款状态）

**③ 效果数据**
- 记录发布后的曝光量、互动率、点击数
- 手动填写实际效果数据存档

**④ 沟通记录**
- 手动添加每次沟通的时间、方式（DM / 邮件 / 电话 / 其他）和内容摘要
- 摘要输入框支持 `@` 提及队友，选中后名字以蓝色高亮显示
- 记录保存后自动更新"最后联系日期"
- 按时间倒序展示所有历史沟通

**⑤ 操作日志**
- 自动记录所有字段变更（谁在什么时候改了什么）
- 不可编辑，用于审计和回溯

**⑥ 归因追踪**
- 为该红人生成唯一 slug 追踪链接（如 `/api/track/username-ab12`）
- 设置跳转目标 URL（落地页地址）
- 实时显示总点击数、总转化数、转化率
- **30 天点击趋势折线图**：直观看出每天点击量变化
- 提供嵌入代码，在落地页 `<head>` 中放置后可自动上报转化事件

### 合作阶段体系

系统内置 11 个阶段，覆盖完整合作周期：

| 阶段 | 含义 |
|------|------|
| 待接触 | 还没联系过 |
| 已发DM | 发了消息，等回复 |
| 谈判中 | 在谈价格和合作细节 |
| 已签约 | 合同确认 |
| 合作中-Draft1 | 等待第一稿 |
| 合作中-Draft2 | 修改后等待第二稿 |
| 待发布 | 内容已审核，等发布 |
| 已发送 | 内容已发布 |
| 已发Invoice | 已发送发票 |
| 已付款 | 款项已到账 |
| 完成 | 全流程结束 |

## 本地运行

**前置条件**：Node.js 18+，一个 Supabase 项目

```bash
# 1. 克隆
git clone https://github.com/YoriHan/kol-tracker.git
cd kol-tracker

# 2. 安装依赖
npm install

# 3. 配置环境变量
# 新建 .env.local，填入：
# NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
# NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...

# 4. 初始化数据库
# 在 Supabase SQL 编辑器中执行 supabase/schema.sql

# 5. 启动
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)，注册账号即可使用。
